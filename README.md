# 🎨 ColorCode

MyColorCode is a simple and fun game where a color name is displayed, and the player has to pick the matching color from multiple options. It’s designed to test and improve color recognition skills.

🔧 Features
Displays a color name or code.

Multiple color choices for the player to select from.

Immediate feedback on correct or incorrect picks.

Simple and engaging UI.

💡 Technologies Used
HTML & CSS – For structure and styling.

JavaScript – To handle game logic and user interaction.





## Deployment

To deploy this project run

```bash
  Yarn dev 
```
